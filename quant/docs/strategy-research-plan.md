# 策略研究计划需求

> 状态：产品需求已确认，尚未进入开发
>
> 确认日期：2026-07-27
>
> 适用范围：A 股日频研究、模拟回测与外部手工决策

## 1. 背景

当前策略提示提供信号日期、策略、提示类型、信号日收盘价和触发原因。用户能够知道策略状态发生了变化，但仍需要自行拼接以下信息：

- 信号使用哪一天的数据，当前行情是否已经偏离信号环境。
- 是否存在可客观计算的进场观察区间。
- 哪个条件代表研究假设失效，能否换算成价格参考线。
- 策略是否配置止盈，止盈与策略退出有何区别。
- 当前退出条件是什么，是否能计算出当日参考线。
- 同一组规则在历史上的收益、回撤、胜率、交易次数和成本假设。

系统需要把这些信息组织成可理解、可追溯的“策略研究计划”，帮助用户研究和复核策略。该计划不是订单，不连接券商，也不代替用户作出真实买卖决定。

## 2. 已确认决策

1. 覆盖全部六种策略模板，包括四种单标的策略和两种组合策略。
2. 无法从策略规则和当日数据客观计算价格区间时，不生成价格区间，改为展示条件、阈值和当前状态。
3. 止盈是可选策略参数，默认关闭。启用后必须进入信号计算、回测和结果解释，不能只在页面展示。
4. 当前处于产品设计阶段，不要求兼容既有信号 API、旧 `reason` JSON 或既有派生信号记录。
5. 完整性优先。全覆盖是信息模型和用户工作流的覆盖，不要求所有策略展示相同字段。

## 3. 产品边界

### 3.1 允许提供

- 信号日收盘价。
- 由策略规则客观计算的进场观察线或观察区间。
- 风险失效条件和可计算的风险参考线。
- 可选止盈条件和可计算的止盈参考线。
- 策略原生退出条件及当日可计算的退出参考线。
- 组合策略的调仓日期、目标权重、纳入与调出原因。
- 与当前策略参数一致的历史回测证据。

### 3.2 不提供

- “建议买入价”“目标卖出价”“可直接照做”等交易指令。
- 对未来准确成交价、退出日期或收益的承诺。
- 盘中自动触发、自动下单、半自动下单或券商连接。
- 未进入回测规则的页面专用止盈、止损或价格区间。
- 为了字段齐全而推测或伪造价格范围。

### 3.3 日频口径

- 所有策略条件默认在 T 日收盘后确认。
- 模拟成交统一使用 T+1 日开盘价，并计入费用、滑点和可成交性约束。
- 盘中快照只用于展示计划是否偏离，不作为已确认的日频信号。
- 止盈、止损和策略退出默认按收盘条件确认。若未来支持盘中触发，必须作为新的策略语义单独设计和回测。

## 4. 目标与非目标

### 4.1 产品目标

- 用户能在一个连续阅读流中理解信号、进场观察、风险、退出和历史证据。
- 新手看到中文结论，进阶用户可展开公式、参数和中间值。
- 每个数值都能追溯到策略版本、参数快照、数据日期和计算依据。
- 单标的与组合策略使用统一框架，同时保留不同策略的真实语义。
- 页面展示规则、信号引擎和回测引擎使用同一套策略定义。

### 4.2 非目标

- 不替用户决定是否交易、交易数量或真实成交价格。
- 不提供个性化投资建议或风险承受能力匹配。
- 不把日频系统扩展为盘中交易系统。
- 本需求不包含开发排期、数据库迁移方案或券商执行能力。

## 5. 核心概念

| 概念 | 定义 |
|---|---|
| 信号日收盘价 | 形成信号的交易日收盘价，仅用于说明信号环境，不是建议成交价。 |
| 进场观察线 | 策略能够客观计算的单一触发价格，例如过去 N 日高点。 |
| 进场观察区间 | 在观察线基础上结合已配置容忍参数得到的区间。没有容忍参数时只显示观察线。 |
| 风险失效条件 | 研究假设不再成立的规则，可以是价格线、指标关系或组合资格变化。 |
| 风险参考线 | 风险失效条件在当前数据下能够换算出的价格。 |
| 止盈条件 | 用户在策略实例中主动启用的可选退出覆盖层，默认关闭。 |
| 策略原生退出 | 算法模板本身定义的退出规则，例如均线下穿、跌破区间低点或 RSI 修复。 |
| 策略研究计划 | 信号、价格参考、风险、退出规则、组合变化和历史证据的版本化快照。 |
| 计划状态 | 当前有效、需要重新评估、已失效、已触发退出或已过期。 |

## 6. 用户故事

### 6.1 单标的入场提示

作为查看入场提示的用户，我希望看到信号为何产生、数据截至哪一天、是否存在客观进场观察线、当前价格是否已经偏离，以便决定是否继续研究。

验收重点：

- 信号原因、信号日收盘价和数据日期同时出现。
- 有客观价格阈值时展示观察线或区间，没有时明确说明该策略按指标关系判断。
- 当前价格超出有效范围时显示“需要重新评估”，不继续显示为正常有效。

### 6.2 单标的持有与退出

作为研究策略持有状态的用户，我希望区分风险止损、可选止盈和策略原生退出，以便理解每种退出的原因，而不是把所有卖出都称为止盈。

验收重点：

- 三类退出分别命名并解释。
- 能计算价格线时显示当前参考值和数据日期。
- 动态条件不能预先换算成未来准确卖出价时，展示规则和当前距离。

### 6.3 组合策略调仓

作为使用组合策略的用户，我希望看到本次调仓新增、保留、减仓、清仓的股票及目标权重变化，以便理解组合如何从评分和风险规则得到新的模拟持仓。

验收重点：

- 展示调仓基准日、下一模拟成交日、股票池和目标权重。
- 每只股票展示纳入、保留、调出或风险过滤原因。
- 没有单股价格区间时不显示空洞占位，改为展示排名、分数、权重和资格条件。

### 6.4 历史验证

作为准备参考研究计划的用户，我希望看到与当前策略版本和参数完全一致的回测结果，以便判断规则是否具有历史稳定性及其风险水平。

验收重点：

- 回测结果明确绑定策略版本、参数、风险覆盖层和费用假设。
- 至少展示区间收益、最大回撤、胜率、交易次数和回测区间。
- 若没有同配置回测，明确显示“尚未验证”，不得借用其他参数结果。

## 7. 统一研究计划模型

### 7.1 基础信息

每份计划必须包含：

- 策略实例和算法模板。
- 策略版本或不可变参数快照。
- 计划类型：单标的计划或组合调仓计划。
- 数据基准日、生成时间和下一模拟成交日。
- 信号类型或调仓类型。
- 当前计划状态及状态原因。

### 7.2 进场观察

进场观察对象支持以下形态：

1. `none`：策略不存在客观价格阈值，展示条件关系。
2. `line`：存在单一价格观察线。
3. `range`：存在观察线和明确配置的容忍参数，可生成上下界。
4. `portfolio_rebalance`：组合策略展示目标权重变化，不生成单股进场区间。

进场观察信息必须包含：

- 计算依据和中文解释。
- 关键参数及单位。
- 数据日期。
- 观察线、上下界或条件当前值。
- 有效期限和需要重新评估的条件。

### 7.3 统一风险覆盖层

所有策略实例都可以配置统一风险覆盖层，但默认关闭。模板原生风险规则仍然保留。

支持的配置类型：

- 固定百分比风险线：相对模拟入场价计算。
- ATR 风险线：相对模拟入场价按 ATR 倍数计算。
- 模板原生风险规则：例如平台下沿、长期均线或组合资格过滤。

展示要求：

- 区分“模板原生风险”和“用户启用的风险覆盖层”。
- 同时存在时展示全部规则，并说明哪个规则先触发就先形成退出状态。
- 风险线随数据变化时，显示当前值和计算日期。

### 7.4 可选止盈覆盖层

- 默认关闭，不给所有策略强加固定止盈。
- 用户启用后，止盈参数成为策略实例的一部分。
- 支持固定收益率或 ATR 倍数两类研究参数。
- 止盈条件按日频收盘确认，T+1 开盘模拟退出。
- 止盈必须进入信号生成、交易明细、回测指标和退出原因统计。
- 关闭止盈时显示“未设置止盈，按风险规则或策略原生条件退出”。

### 7.5 退出规则与优先级

退出原因分为：

1. 风险覆盖层触发。
2. 止盈覆盖层触发。
3. 策略原生退出触发。
4. 组合调仓或资格变化。

若同一收盘日满足多个条件：

- 保存全部命中原因，不能只保留一个模糊的“退出”。
- 主原因按风险覆盖层、止盈覆盖层、策略原生退出、组合调仓的顺序显示。
- 实际模拟退出时间仍为下一交易日开盘。

### 7.6 重新进入规则

- 单标的策略因风险或止盈覆盖层退出后，不允许在原入场条件持续为真时立即重新进入。
- 重新进入需要原入场条件先失效，再次从未满足变为满足。
- 组合策略因覆盖层退出后，保持目标权重为零，直到下一次计划调仓重新获得资格。
- 模板原生的日常风险恢复逻辑需要在策略说明中单独展示，不能与覆盖层退出混为一谈。

## 8. 六种策略覆盖矩阵

| 策略 | 计划类型 | 进场或调仓表达 | 原生退出或风险 | 价格区间策略 |
|---|---|---|---|---|
| 双均线趋势 | 单标的 | 展示快慢均线关系、交叉日期和信号日收盘价 | 快线下穿慢线 | 默认不生成价格区间；可展示均线当前值和距离 |
| 价格突破 | 单标的 | 展示过去 N 日高点作为观察线 | 跌破过去 M 日低点 | 配置最大溢价容忍后可生成观察区间，否则只显示突破线 |
| 上升趋势中的超跌反弹 | 单标的 | 展示 RSI 阈值、长期均线和当前值 | RSI 修复或跌破长期均线 | 默认不生成价格区间，避免把指标组合伪造成固定价格 |
| 缩量整理后的放量突破 | 单标的 | 展示平台上沿、量能阈值和突破状态 | 平台下沿或 ATR 风险线 | 配置最大溢价容忍后可生成观察区间，否则只显示平台上沿 |
| 强势股票轮动 | 组合 | 展示周度调仓、Top N、评分、目标权重和新增/调出名单 | 跌破 20 日均线的资格过滤 | 不生成单股进场区间；展示目标权重和风险过滤线 |
| 多指标综合评分持有 | 组合 | 展示月度调仓、排名、评分分解、目标权重和调出原因 | 月度排名变化及可选覆盖层 | 不生成单股进场区间；展示调仓计划和权重变化 |

全覆盖的含义是六种策略都有完整、符合自身语义的计划，不是六种策略都必须拥有进场价格区间。

## 9. 计划状态与有效期

| 状态 | 含义 |
|---|---|
| 当前有效 | 当前快照未违反计划的明确有效条件。 |
| 需要重新评估 | 高开、低开、价格越过观察区间、数据日期变化或关键条件明显偏离。 |
| 已失效 | 原入场条件在新的已确认收盘数据中不再成立。 |
| 已触发退出 | 收盘数据满足风险、止盈、原生退出或组合调仓条件。 |
| 已过期 | 计划超过有效期限且没有基于新数据刷新。 |

默认有效期：

- 单标的入场研究计划默认只覆盖下一个交易日。
- 下一交易日收盘后，无论是否手工交易，都基于新数据生成新状态。
- 组合调仓计划持续到本次计划成交日完成或下一份调仓计划替代。

## 10. 页面信息架构

### 10.1 信号提醒

- 将现有“参考价格”改名为“信号日收盘价”。
- 列表保留日期、股票、策略、提示、信号日收盘价和原因。
- 行展开后显示策略研究计划摘要，不使用弹窗。
- 摘要顺序：数据与信号、进场观察、风险与退出、历史验证、产品边界。

### 10.2 个股页

- K 线图按需叠加信号日、观察线或区间、风险线、止盈线和原生退出线。
- 每条线同时显示名称、数值和数据日期，不能只依赖颜色。
- 无法计算价格线的条件展示在图表下方的结构化规则区。
- 计划状态和“需要重新评估”原因紧邻当前行情，不藏在 tooltip 中。

### 10.3 策略管理

- 模板原生参数和统一风险覆盖层分区展示。
- 止盈使用明确开关，关闭时不显示无效输入框。
- 开启止盈或风险覆盖层后，实时展示规则摘要，但不在无行情数据时伪造价格。
- 公共策略仍然只读；需要调整参数时继续使用“另存为我的策略”。

### 10.4 策略回测

- 结果页展示本次回测使用的完整策略参数、风险覆盖层、止盈配置和费用假设。
- 增加退出原因分布和逐笔模拟交易明细。
- 逐笔记录区分信号日、模拟成交日、模拟成交价和退出原因。
- 参数扫描必须包含新增风险和止盈参数，避免只扫描原生模板参数。

### 10.5 组合策略

- 使用“调仓研究计划”而不是单标的“进场计划”。
- 展示股票池、调仓频率、计划日期、下一模拟成交日、目标权重变化和现金权重。
- 每只股票显示新增、保留、减仓、清仓或风险过滤原因。
- 可选风险与止盈覆盖层按持仓逐只计算，但汇总到组合风险视图。

## 11. 文案规范

推荐使用：

- 信号日收盘价
- 进场观察线
- 进场观察区间
- 风险失效线
- 止盈参考线
- 策略退出条件
- 调仓目标权重
- 需要重新评估
- 日频研究参考

禁止使用：

- 建议买入价
- 推荐卖出价
- 最佳进场点
- 可直接照做
- 保证止损
- 确定性收益
- 系统替你交易

统一边界文案：

> 本计划根据日频数据和策略规则生成，仅用于研究。真实买卖、价格、数量和风险决策由你在外部交易应用中确认。

## 12. 数据与可追溯性要求

每份研究计划需要保存或能够稳定复现：

- 策略实例 ID、算法模板和策略版本。
- 完整参数快照，包括风险与止盈覆盖层。
- 数据基准日、生成时间和价格复权口径。
- 信号状态、目标仓位或目标权重变化。
- 观察线、区间、风险线、止盈线和退出线的计算结果。
- 所有命中原因和中文解释所需的结构化字段。
- 对应回测 ID、回测区间和费用假设。

既有派生信号不要求兼容旧结构，可以删除后按新模型重算。用户策略、手工成交记录等非派生业务数据不在本需求的删除范围内。

## 13. 接口级产品契约

具体数据库表和 URL 在技术设计阶段确定，但产品层要求以下能力：

- 查询信号时返回计划摘要和计划状态。
- 按计划 ID 查询完整计算依据、价格参考、退出规则和回测证据。
- 查询策略模板时返回计划能力声明，说明支持哪些价格线和条件类型。
- 运行回测时返回逐笔模拟交易、退出原因和计划参数快照。
- 查询组合调仓计划时返回逐股目标权重变化和原因。
- 所有对外名称来自统一中文词典，不暴露内部 JSON。

## 14. 异常与边界场景

- 非交易日或行情未更新：不生成新计划。
- 次日停牌：标记无法按回测假设成交，计划需要重新评估。
- 次日涨跌停：按真实可成交约束处理，不假设能够成交。
- 高开或低开越过观察区间：不把区间端点当作可成交价，标记需要重新评估。
- ATR、均线、RSI 或历史窗口不足：对应价格线或条件显示数据不足。
- 股票除权除息：使用统一前复权序列计算，界面注明价格口径。
- 多个退出条件同日命中：保存全部原因并按既定优先级展示。
- 同策略参数已修改：历史计划继续展示当时快照，不能用当前参数重算说明。
- 无同参数回测：显示尚未验证，不展示其他参数的结果作为替代。
- 组合股票池缺失历史成分：计划和回测明确报错，不用当前成分替代。

## 15. 验收标准

### 15.1 通用

- 六种策略模板都能生成符合自身语义的研究计划。
- 所有计划显示数据日期、策略参数快照、计算依据和产品边界。
- 无客观价格范围时不生成范围，也不显示误导性空值。
- 页面、信号引擎和回测引擎使用同一套止盈、风险和退出规则。
- 任何真实交易动作都不会由系统生成、提交或自动执行。

### 15.2 单标的策略

- 用户能区分信号日收盘价、进场观察、风险失效、止盈和原生退出。
- 信号形成于 T 日收盘，模拟成交发生在 T+1 开盘。
- 动态退出条件不能显示成预先确定的未来卖出价。
- 覆盖层退出后需要重新满足入场边沿才能再次进入。

### 15.3 组合策略

- 调仓计划展示目标权重和逐股变化原因。
- 不将组合调仓强行表达为单股买入区间。
- 可选风险和止盈覆盖层对每只持仓生效，并进入组合回测。
- 覆盖层退出后最早在下一次计划调仓重新获得资格。

### 15.4 交互与可访问性

- 列表保持紧凑，完整信息通过行展开或个股页渐进展示。
- 不使用只有颜色才能识别的风险或状态表达。
- 所有展开、切换和配置控件支持键盘操作并有清晰焦点。
- 小屏幕优先保持结论、日期和状态可读，宽表允许横向浏览。
