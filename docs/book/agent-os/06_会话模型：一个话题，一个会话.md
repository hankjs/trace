卡片没变，系统内部要多出一条线

飞书群按消息的组织方式，可以分成普通群和话题群。两者都能发消息和回复，真正的区别是：消息是否被组织成一条条独立的话题。

普通群：所有人的消息都按时间排在同一条聊天流里。你可以引用某条消息回复，但新回复仍然会出现在群聊的最下方。几个任务同时讨论时，消息容易交错在一起。
话题群：每次发起新内容都可以成为一个独立话题，后续回复都收在这个话题下。群里可以同时存在多个话题，但每个话题都有自己的上下文，不会被其他讨论打断。

对 Agent OS 来说，这个区别很关键。用户在一个话题里发起任务、补充信息和追问进度，这些消息本来就属于同一条任务线。因此，我们可以把一个飞书话题映射成一个 Session，让 Bot 在后续回复中一直保留这段上下文。

前面解析消息时，我们已经拿到了 threadId、rootId 和 messageId。现在要用这些字段回答一个问题：这条新消息应该进入哪段会话？

飞书会给每个话题一个 threadId（omt_ 开头）。话题里的回复还可能带有 rootId（om_ 开头），它其实是话题首条消息的 messageId。两者的值不一样，但指向的是同一段讨论，所以都可以用来找到这个话题对应的 Session。

所以，我们优先用 threadId 查找 Session；没有 threadId 时再用 rootId；两者都没有，说明这条消息不属于任何话题，通常来自普通群或单聊，就用它自己的 messageId 创建 Session。用代码表示就是：

typescript
复制
threadId || rootId || messageId;


这里还要把 chatId 放进键里。用 chatId:threadId 作为 id 基本就能唯一表示一个 session 了。

我觉得话题是对任务非常好的一个抽象。话题标题描述任务，追问和截图自然留在里面，/close 也只影响这一条任务线。以后接入真实执行引擎，模型上下文、工作目录和任务卡片都会挂在同一个 Session 下。

import { randomUUID } from "node:crypto";

export type CliId = "claude";

export type SessionStatus = "creating" | "active" | "idle" | "closed";

export interface Session {
  id: string;
  threadId: string;
  chatId: string;
  cliId: CliId;
  status: SessionStatus;
  createdAt: string;
  updatedAt: string;
}

export interface MessageAddress {
  messageId: string;
  chatId: string;
  threadId: string;
  rootId: string;
}

export interface ResolvedSession {
  session: Session;
  isNew: boolean;
}

export interface SessionManagerOptions {
  now?: () => Date;
  createId?: () => string;
}

const ALLOWED_TRANSITIONS: Record<SessionStatus, SessionStatus[]> = {
  creating: ["active", "closed"],
  active: ["idle", "closed"],
  idle: ["active", "closed"],
  closed: [],
};


先解释一下里面各个 id 的含义：

id 是 Agent OS 自己的会话 ID，通过 Node.js 的 randomUUID() 生成。
threadId 负责找到飞书话题。
chatId 划定群聊范围。
cliId 记录以后交给哪个执行引擎，比如 Claude Code 或者 Codex。

当前只接 Claude Code，等第二个 CLI 真正进来时再扩展联合类型。

这里其实有两层会话。Agent OS 的 Session 管消息路由和任务状态，Claude Code 自己的会话负责保存模型对话。后面真正调用 Claude Code 时，它会返回另一段会话 ID；我们会把那段 ID 存进当前 Session，同话题追问时再交给 Claude Code 恢复上下文。

这两层边界分开以后，系统会好维护很多。

Session 状态只有四个：

creating：刚从消息创建，还没开始执行；
active：任务正在运行；
idle：上一轮已经结束，可以接收追问；
closed：会话明确结束，同一话题不再接任务。

ALLOWED_TRANSITIONS 相当于是个状态集的限制，规定了某个状态后面只能接特定的一些状态，比如 active 后面直接变为 idle 或者 closed。

接着在同一个文件里补上 Session 管理器：

src/core/session-manager.ts
复制
function topicIdOf(message: MessageAddress): string {
  return message.threadId || message.rootId || message.messageId;
}

function sessionKey(chatId: string, threadId: string): string {
  return `${chatId}:${threadId}`;
}

export class SessionManager {
  private readonly sessions = new Map<string, Session>();
  private readonly now: () => Date;
  private readonly createId: () => string;

  constructor(options: SessionManagerOptions = {}) {
    this.now = options.now ?? (() => new Date());
    this.createId = options.createId ?? randomUUID;
  }

  get size(): number {
    return this.sessions.size;
  }

  get(sessionId: string): Session | undefined {
    return [...this.sessions.values()].find(
      (session) => session.id === sessionId,
    );
  }

  resolve(message: MessageAddress): ResolvedSession {
    const threadId = topicIdOf(message);
    const key = sessionKey(message.chatId, threadId);
    const existing = this.sessions.get(key);
    if (existing) return { session: existing, isNew: false };

    const now = this.now().toISOString();
    const session: Session = {
      id: this.createId(),
      threadId,
      chatId: message.chatId,
      cliId: "claude",
      status: "creating",
      createdAt: now,
      updatedAt: now,
    };
    this.sessions.set(key, session);
    return { session, isNew: true };
  }

  transition(sessionId: string, nextStatus: SessionStatus): Session {
    const current = this.get(sessionId);
    if (!current) throw new Error(`会话不存在: ${sessionId}`);
    if (!ALLOWED_TRANSITIONS[current.status].includes(nextStatus)) {
      throw new Error(`会话 ${current.status} 不能切换到 ${nextStatus}`);
    }

    const updated: Session = {
      ...current,
      status: nextStatus,
      updatedAt: this.now().toISOString(),
    };
    this.sessions.set(sessionKey(updated.chatId, updated.threadId), updated);
    return updated;
  }
}


Map 的键是飞书话题地址，值是完整 Session。resolve() 每次收到消息都会先查一次：查到就返回原会话，查不到才创建。返回值里的 isNew 专门告诉上层这次发生了哪种路由，后面看日志时会比较直观。

transition() 没有原地修改旧对象，而是生成一份带新状态和新时间的记录，再放回 Map。会话数据只有一个写入口，状态约束也就不会散在各个消息分支里。

新建 src/core/command-parser.ts：

src/core/command-parser.ts

export type CommandName = "close" | "status" | "help";

export interface SlashCommand {
  name: CommandName;
}

const COMMAND_RE = /^(?:@.+\s+)?\/(close|status|help)\s*$/;

export function parseCommand(text: string): SlashCommand | undefined {
  const match = COMMAND_RE.exec(text.trim());
  if (!match) return undefined;
  return { name: match[1] as CommandName };
}


正则允许命令前面带机器人提及，所以 @MyBot /status 和 /status 都能识别。@.+\s+ 也覆盖了机器人名称里有空格的情况，比如 @Agent OS /status。

普通文本里顺手提一句「帮我运行 /status 看看」不会被当成命令。整段文本必须符合「可选的 @提及 + 一条受支持命令」，解析才会成功。

/close 还要停掉正在刷新的任务

刚才在任务完成后执行 /close 没问题。如果任务还在跑，单纯把状态写成 closed，后台的 runCardDemo() 仍会继续更新卡片。用户已经关闭会话，卡片却还在往前走，这就冲突了。

我们用 AbortController 把关闭动作传给 Agent OS 后台的任务。

先打开 src/im/card.ts，在 finish() 后面增加取消能力：

async cancel(): Promise<void> {
  if (this.closed) return;
  this.closed = true;
  if (this.timer) clearTimeout(this.timer);
  this.timer = undefined;
  this.pendingCard = undefined;
  await this.updateChain;
}


cancel() 会清掉还没发送的卡片和定时器，并等待已经发出的更新结束。它不会再提交最终的成功卡片，所以用户看到的进度会停在关闭前的位置。

const sessions = new SessionManager();
const activeRuns = new Map<string, AbortController>();

function wait(ms: number, signal: AbortSignal): Promise<boolean> {
  if (signal.aborted) return Promise.resolve(false);

  return new Promise((resolve) => {
    const timer = setTimeout(() => {
      signal.removeEventListener("abort", stopWaiting);
      resolve(true);
    }, ms);
    const stopWaiting = () => {
      clearTimeout(timer);
      resolve(false);
    };
    signal.addEventListener("abort", stopWaiting, { once: true });
  });
}

async function runCardDemo(
  bot: Bot,
  cardId: string,
  resolved: string,
  signal: AbortSignal,
): Promise<void> {
  const activities: string[] = [];
  const updater = new ThrottledCardUpdater(async (card) => {
    await bot.updateCard(cardId, card);
    console.log("[卡片] 已刷新");
  });

  for (const [index, step] of DEMO_STEPS.entries()) {
    if (!(await wait(700, signal))) {
      await updater.cancel();
      console.log("[卡片] 任务已取消");
      return;
    }
    activities.push(step);
    const progress = Math.round(((index + 1) / DEMO_STEPS.length) * 90);
    console.log(`[进度] ${progress}% ${step}`);
    updater.push(
      buildTaskCard({
        title: "Agent OS 模拟任务",
        status: "running",
        progress,
        detail: step,
        activities: activities.slice(-3),
      }),
    );
  }

  await updater.finish(
    buildTaskCard({
      title: "Agent OS 模拟任务",
      status: "success",
      progress: 100,
      detail: `已处理：${resolved || "富媒体消息"}`,
      activities: activities.slice(-3),
    }),
  );
  console.log("[卡片] 任务完成");
}

```typescript
import { randomUUID } from "node:crypto";

export type CliId = "claude";

export type SessionStatus = "creating" | "active" | "idle" | "closed";

export interface Session {
  id: string;
  threadId: string;
  chatId: string;
  cliId: CliId;
  status: SessionStatus;
  createdAt: string;
  updatedAt: string;
}

export interface MessageAddress {
  messageId: string;
  chatId: string;
  threadId: string;
  rootId: string;
}

export interface ResolvedSession {
  session: Session;
  isNew: boolean;
}

export interface SessionManagerOptions {
  now?: () => Date;
  createId?: () => string;
}

const ALLOWED_TRANSITIONS: Record<SessionStatus, SessionStatus[]> = {
  creating: ["active", "closed"],
  active: ["idle", "closed"],
  idle: ["active", "closed"],
  closed: [],
};
```


```typescript
function topicIdOf(message: MessageAddress): string {
  return message.threadId || message.rootId || message.messageId;
}

function sessionKey(chatId: string, threadId: string): string {
  return `${chatId}:${threadId}`;
}

export class SessionManager {
  private readonly sessions = new Map<string, Session>();
  private readonly now: () => Date;
  private readonly createId: () => string;

  constructor(options: SessionManagerOptions = {}) {
    this.now = options.now ?? (() => new Date());
    this.createId = options.createId ?? randomUUID;
  }

  get size(): number {
    return this.sessions.size;
  }

  get(sessionId: string): Session | undefined {
    return [...this.sessions.values()].find(
      (session) => session.id === sessionId,
    );
  }

  resolve(message: MessageAddress): ResolvedSession {
    const threadId = topicIdOf(message);
    const key = sessionKey(message.chatId, threadId);
    const existing = this.sessions.get(key);
    if (existing) return { session: existing, isNew: false };

    const now = this.now().toISOString();
    const session: Session = {
      id: this.createId(),
      threadId,
      chatId: message.chatId,
      cliId: "claude",
      status: "creating",
      createdAt: now,
      updatedAt: now,
    };
    this.sessions.set(key, session);
    return { session, isNew: true };
  }

  transition(sessionId: string, nextStatus: SessionStatus): Session {
    const current = this.get(sessionId);
    if (!current) throw new Error(`会话不存在: ${sessionId}`);
    if (!ALLOWED_TRANSITIONS[current.status].includes(nextStatus)) {
      throw new Error(`会话 ${current.status} 不能切换到 ${nextStatus}`);
    }

    const updated: Session = {
      ...current,
      status: nextStatus,
      updatedAt: this.now().toISOString(),
    };
    this.sessions.set(sessionKey(updated.chatId, updated.threadId), updated);
    return updated;
  }
}
```

```typescript
function wait(ms: number, signal: AbortSignal): Promise<boolean> {
  if (signal.aborted) return Promise.resolve(false);

  return new Promise((resolve) => {
    const timer = setTimeout(() => {
      signal.removeEventListener("abort", stopWaiting);
      resolve(true);
    }, ms);
    const stopWaiting = () => {
      clearTimeout(timer);
      resolve(false);
    };
    signal.addEventListener("abort", stopWaiting, { once: true });
  });
}
```
